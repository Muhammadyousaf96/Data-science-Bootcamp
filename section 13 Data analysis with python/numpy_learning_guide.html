What is NumPy?
section 01 / introduction

The Foundation of Scientific Python

NumPy (Numerical Python) is the fundamental package for numerical computing in Python. At its core, it introduces the ndarray — a powerful N-dimensional array object that is dramatically faster and more memory-efficient than Python's built-in lists.

Think of NumPy as giving Python "superpowers" for math: instead of looping over thousands of data points one-by-one, NumPy lets you process entire datasets in a single instruction.

💡
Why is NumPy so fast?
NumPy arrays are stored as contiguous blocks of memory with a fixed type (like C arrays), allowing the CPU to process them with vectorized instructions. Python lists, by contrast, store pointers to arbitrary objects scattered in memory.

Why NumPy for Data Analysis?

  • Speed: NumPy operations run 10–100× faster than pure Python loops on numerical data.
  • Memory efficiency: A NumPy array of 1 million integers uses ~8 MB; a Python list uses ~35 MB.
  • Expressive syntax: Operations like "multiply every price by 1.1" are one-liners.
  • Foundation of the ecosystem: Pandas, Matplotlib, Scikit-learn, and TensorFlow all build on NumPy arrays.
  • Rich statistical functions: mean, median, std, percentile — all built in.
Python — why NumPy is faster 
import numpy as np
import time

# Create 1 million numbers
data_list = list(range(1_000_000))
data_np   = np.arange(1_000_000)

# Python list — loop approach
t1 = time.time()
result = [x * 2 for x in data_list]
print(f"Python list: {time.time() - t1:.4f}s")   # ~0.08s

# NumPy — vectorized approach
t2 = time.time()
result = data_np * 2
print(f"NumPy array: {time.time() - t2:.4f}s")   # ~0.001s

Python — indexing & slicing 
scores = np.array([
    [85, 92, 78, 96],
    [70, 88, 91, 65],
    [55, 72, 68, 80],
])

# ── Basic indexing ─────────────────────────────────
scores[0, 2]      # 78  ← row 0, col 2 (single value)
scores[1]         # [70, 88, 91, 65]  ← entire row 1
scores[:, 0]      # [85, 70, 55]  ← col 0 (all rows)

# ── Slicing ────────────────────────────────────────
scores[0:2, 1:3]   # rows 0-1, cols 1-2 → [[92,78],[88,91]]
scores[:, 1:3]    # all rows, cols 1 and 2
scores[::2]       # every other row
scores[:, ::-1]   # reverse column order

# ── Boolean (Fancy) Indexing — very powerful! ──────
marks = np.array([45, 82, 59, 90, 71, 38, 95])

# Who passed? (marks >= 60)
passed = marks[marks >= 60]
print(passed)   # [82, 90, 71, 95]

# Who scored between 60 and 85?
average = marks[(marks >= 60) & (marks <= 85)]
print(average)  # [82, 71]

# Replace failing marks with 0 (data cleaning!)
marks[marks < 60] = 0
print(marks)    # [0, 82, 0, 90, 71, 0, 95]

# ── Fancy indexing with arrays ─────────────────────
prices = np.array([200, 450, 125, 780, 310])
selected = prices[[0, 2, 4]]  # pick specific items by index
print(selected)               # [200, 125, 310]
⚠️
Views vs Copies — Critical Gotcha!
NumPy slices are views, not copies. Changing a slice changes the original array! Use arr[1:3].copy() to create an independent copy when needed.

Data Types (dtype)
section 04 / memory & precision

Why Data Types Matter in Analysis

Every NumPy array has a single data type (dtype). Unlike Python where a list can hold mixed types, NumPy arrays are homogeneous — all elements share one type. This is what makes them fast, but you need to choose types wisely.

Wrong dtype = wasted memory or silent precision loss. For example, storing percentages (0.0–1.0) as int32 will truncate them all to 0!

dtypeRange / PrecisionWhen to Use
int8-128 to 127Small counts, flags, labels
int32-2B to 2BGeneral integers (IDs, counts)
int64very large integersUnix timestamps, large IDs
float32~7 decimal digitsML weights, large float datasets
float64~15 decimal digitsDefault for most analysis
boolTrue / FalseMasks, filters
complex128complex numbersSignal processing, FFT
Python — working with dtypes 
# ── Check and specify dtype ────────────────────────
a = np.array([1, 2, 3])
print(a.dtype)                     # int64 (default on 64-bit systems)

b = np.array([1, 2, 3], dtype=np.float32)
print(b.dtype)                     # float32

# ── Type conversion (casting) ──────────────────────
prices = np.array([19.99, 34.50, 7.25])
int_prices = prices.astype(np.int32)
print(int_prices)                  # [19, 34, 7] ← decimal truncated!

# ── Real example: memory saving ───────────────────
large = np.random.randint(0, 255, size=(1000, 1000))
print(large.nbytes)                # 8,000,000 bytes (int64)
small = large.astype(np.uint8)   # pixel values 0-255 fit in uint8
print(small.nbytes)                # 1,000,000 bytes ← 8× savings!

# ── Watch out for integer overflow! ───────────────
x = np.array([200], dtype=np.int8)
print(x + 100)  # [-44]  ← 300 overflows int8 range!
🚫
Common Mistake: Mixing Integers and Floats
If you create an array like np.array([1, 2, 3]) and divide by 2, you get [0, 1, 1] (integer division)! Always ensure your array is float first: np.array([1.0, 2.0, 3.0]) or .astype(float).

Array Operations
section 05 / math & statistics

Vectorized Math — No Loops Needed

The power of NumPy is that you can apply operations to entire arrays at once. An operation like prices * 1.1 applies the multiplication to every element simultaneously — this is called vectorization.

Python — mathematical operations 
sales = np.array([1200, 1450, 980, 2100, 1750, 890])

# ── Element-wise arithmetic ────────────────────────
sales * 1.15          # apply 15% price increase to all
sales - 100           # subtract 100 from each (discount)
sales ** 2            # square each value
np.sqrt(sales)        # square root of each
np.log(sales)         # natural log (useful for log-normal data)

# ── Two arrays: element-wise ───────────────────────
cost   = np.array([800, 900, 600, 1500, 1000, 500])
profit = sales - cost
margin = (profit / sales) * 100   # profit margin %
print(np.round(margin, 1))         # [33.3, 37.9, 38.8, 28.6, 42.9, 43.8]
Python — statistical operations (the heart of data analysis) 
marks = np.array([[85, 92, 78, 96],
                    [70, 88, 91, 65],
                    [55, 72, 68, 80]])

# ── Global statistics ──────────────────────────────
print(np.mean(marks))       # 78.33 — overall class average
print(np.median(marks))     # 80.0
print(np.std(marks))        # standard deviation
print(np.min(marks))        # 55 — lowest score overall
print(np.max(marks))        # 96 — highest score
print(np.percentile(marks, 75))  # 75th percentile = 90.25

# ── Axis-based statistics (super useful!) ──────────
# axis=0 → collapse rows (result per COLUMN = per subject)
subject_avg = np.mean(marks, axis=0)
print(subject_avg)   # [70.0, 84.0, 79.0, 80.3] — avg per subject

# axis=1 → collapse columns (result per ROW = per student)
student_avg = np.mean(marks, axis=1)
print(student_avg)   # [87.75, 78.5, 68.75] — avg per student

# ── Finding positions ──────────────────────────────
print(np.argmax(student_avg))  # 0 — student 0 has highest avg
print(np.argsort(student_avg)) # [2, 1, 0] — sorted ranking

# ── Cumulative operations ──────────────────────────
monthly_sales = np.array([100, 150, 120, 200])
print(np.cumsum(monthly_sales)) # [100, 250, 370, 570] — running total
📌
Understanding axis=0 vs axis=1
axis=0 operates "down the rows" → produces one result per column. axis=1 operates "across the columns" → produces one result per row. A helpful mnemonic: axis=0 is the "column aggregator", axis=1 is the "row aggregator".

Broadcasting
section 06 / the magic rule

Operations Between Arrays of Different Shapes

Broadcasting is NumPy's mechanism for performing operations on arrays with different shapes — without copying data. It's one of NumPy's most powerful (and initially confusing) features.

The rule: Arrays are compatible if, starting from the trailing dimensions, their sizes either match or one of them is 1.

Python — broadcasting examples 
scores = np.array([[85, 92, 78, 96],
                    [70, 88, 91, 65],
                    [55, 72, 68, 80]])  # shape (3, 4)

# ── Scalar broadcasting (simplest) ────────────────
scores_scaled = scores * 1.1   # scalar → broadcast to (3,4)

# ── Row vector: normalize each subject ────────────
col_mean = np.mean(scores, axis=0)    # shape (4,)
centered = scores - col_mean           # (3,4) - (4,) → works!

# ── Column vector: subtract each student's avg ────
row_mean = np.mean(scores, axis=1, keepdims=True)  # shape (3,1) ← KEY!
deviation = scores - row_mean              # (3,4) - (3,1) → works!
print(deviation)  # how far each score is from that student's mean

# ── Practical: apply different bonuses per subject ─
subject_weights = np.array([0.3, 0.3, 0.2, 0.2])  # (4,)
weighted_scores = scores * subject_weights          # (3,4) × (4,)
final_grade     = weighted_scores.sum(axis=1)        # (3,)
print(final_grade)  # [87.4, 79.7, 68.7]
⚠️
keepdims=True — Don't Forget It!
When using axis=1 for column operations, the result has shape (3,) but you need (3,1) for broadcasting to work. Always use keepdims=True: np.mean(arr, axis=1, keepdims=True).

Reshaping & Transformation
section 07 / changing structure

Changing Shape Without Changing Data

Often your data comes in one shape but your algorithm needs another. Reshaping operations change the structure of an array without copying its underlying data.

Python — reshaping operations 
# ── reshape ────────────────────────────────────────
flat    = np.arange(12)             # [0,1,2,...,11] shape (12,)
matrix  = flat.reshape(3, 4)        # shape (3,4)
cube    = flat.reshape(2, 2, 3)     # shape (2,2,3)
auto    = flat.reshape(3, -1)       # -1 = "figure it out" → (3,4)
col     = flat.reshape(-1, 1)      # (12,1) → column vector

# ── flatten vs ravel ───────────────────────────────
matrix.flatten()   # returns a COPY: always 1D
matrix.ravel()     # returns a VIEW when possible: faster

# ── transpose ──────────────────────────────────────
data = np.array([[1, 2, 3],
                  [4, 5, 6]])    # shape (2, 3)
data.T                            # shape (3, 2) — rows ↔ columns

# ── stacking & splitting ───────────────────────────
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

np.vstack([a, b])   # [[1,2,3],[4,5,6]] — stack as rows
np.hstack([a, b])   # [1,2,3,4,5,6] — concatenate horizontally
np.column_stack([a, b])  # [[1,4],[2,5],[3,6]] — as 2 columns

# ── Real use case: prepare features for ML ─────────
age    = np.array([25, 32, 41, 28])
salary = np.array([40000, 65000, 90000, 50000])
X = np.column_stack([age, salary])  # (4, 2) feature matrix
print(X.shape)                          # (4, 2) — ready for sklearn!

Common Mistakes & How to Avoid Them
section 08 / don't trip on these
❌ Wrong
a = np.array([1,2,3]) b = a b[0] = 99 # a is also changed!
Assignment creates a reference, not a copy.
✅ Correct
a = np.array([1,2,3]) b = a.copy() b[0] = 99 # a is unchanged ✓
Use .copy() to create an independent array.
❌ Wrong
marks = np.array([85,90,78]) avg = marks / 2 # Works but might give # integer truncation
Array dtype may be integer — division silently truncates.
✅ Correct
marks = np.array([85,90,78], dtype=float) avg = marks / 2.0 # [42.5, 45.0, 39.0] ✓
Specify dtype=float or use float literals.
❌ Wrong
a = np.mean(arr, axis=1) # shape: (3,) result = arr - a # ValueError! ← shape mismatch
Row mean has wrong shape for broadcasting.
✅ Correct
a = np.mean(arr, axis=1, keepdims=True) # shape: (3, 1) result = arr - a # works ✓
Use keepdims=True for row-wise operations.
❌ Wrong
if arr == other_arr: # does element comparison # returns array of bools! # ambiguous truth value error
Never use == to compare arrays directly.
✅ Correct
np.array_equal(arr, other_arr) # Returns True/False ✓ np.allclose(arr, other_arr) # For float comparisons ✓
Use np.array_equal() or np.allclose().
🔍
Debug Like a Pro
When you get a shape error, always print arr.shape for every array involved. 90% of NumPy bugs are shape mismatches. Insert print(arr.shape) liberally while debugging — remove them when done.

Mini Project
section 09 / putting it all together
📊 mini project

Student Examination Analysis System

You've been given marks data for 8 students across 5 subjects. Your task is to build a complete analysis pipeline using only NumPy — calculate stats, assign grades, identify top performers, and normalize scores.

Python — complete mini project 
import numpy as np

# ════════════════════════════════════════════════
# DATASET: 8 students × 5 subjects
# Subjects: Math, Physics, Chemistry, CS, English
# ════════════════════════════════════════════════
marks = np.array([
    [88, 76, 91, 95, 82],   # Ali
    [72, 85, 68, 90, 77],   # Sara
    [55, 60, 48, 70, 65],   # Hamza
    [95, 92, 88, 98, 91],   # Ayesha
    [40, 38, 55, 45, 52],   # Usman
    [78, 82, 75, 80, 88],   # Zara
    [65, 70, 72, 60, 68],   # Bilal
    [82, 88, 85, 79, 90],   # Fatima
], dtype=np.float64)

students = ["Ali", "Sara", "Hamza", "Ayesha",
            "Usman", "Zara", "Bilal", "Fatima"]
subjects = ["Math", "Physics", "Chem", "CS", "Eng"]

# ── STEP 1: Basic Statistics ──────────────────────
student_avg  = np.mean(marks, axis=1)     # per student
student_max  = np.max(marks, axis=1)
student_min  = np.min(marks, axis=1)
student_std  = np.std(marks, axis=1)
subject_avg  = np.mean(marks, axis=0)     # per subject

print("=== STUDENT AVERAGES ===")
for i, name in enumerate(students):
    print(f"  {name:8s}: {student_avg[i]:.1f}  (std: {student_std[i]:.1f})")

print("\n=== SUBJECT AVERAGES ===")
for i, subj in enumerate(subjects):
    print(f"  {subj:10s}: {subject_avg[i]:.1f}")

# ── STEP 2: Grade Assignment using np.where ───────
def assign_grade(avg):
    return np.where(avg >= 90, 'A',
           np.where(avg >= 80, 'B',
           np.where(avg >= 70, 'C',
           np.where(avg >= 60, 'D', 'F'))))

grades = assign_grade(student_avg)
print("\n=== GRADES ===")
for i, name in enumerate(students):
    print(f"  {name:8s}: {grades[i]}  ({student_avg[i]:.1f})")

# ── STEP 3: Rankings ──────────────────────────────
rank_order = np.argsort(student_avg)[::-1]  # descending
print("\n=== STUDENT RANKINGS ===")
for rank, idx in enumerate(rank_order, 1):
    print(f"  #{rank}. {students[idx]:8s}: {student_avg[idx]:.1f}")

# ── STEP 4: Identify At-Risk Students ─────────────
at_risk = student_avg < 60
print("\n=== AT-RISK STUDENTS ===")
at_risk_names = [students[i] for i in np.where(at_risk)[0]]
print(f"  {at_risk_names}")

# ── STEP 5: Score Normalization (0-100 scale) ─────
# Min-max normalize each subject independently
col_min = marks.min(axis=0)
col_max = marks.max(axis=0)
normalized = (marks - col_min) / (col_max - col_min) * 100
print("\n=== NORMALIZED SCORES (first 3 students) ===")
print(np.round(normalized[:3], 1))

# ── STEP 6: Class-wide summary ────────────────────
print("\n=== CLASS SUMMARY ===")
print(f"  Overall average: {np.mean(marks):.1f}")
print(f"  Pass rate:       {(student_avg >= 60).mean()*100:.0f}%")
print(f"  Top scorer:      {students[np.argmax(student_avg)]}")
print(f"  Hardest subject: {subjects[np.argmin(subject_avg)]}")
print(f"  Easiest subject: {subjects[np.argmax(subject_avg)]}")

# ── STEP 7: Correlation between subjects ──────────
corr_matrix = np.corrcoef(marks.T)  # .T gives subject-subject corr
print(f"\n  Math-CS correlation: {corr_matrix[0,3]:.3f}")  # expect high

NumPy → Pandas → Data Science
section 10 / the bigger picture

NumPy

Raw numerical arrays, vectorized math, memory-efficient, low-level operations

→

Pandas

Labeled DataFrames, CSV/SQL I/O, mixed types, built on NumPy arrays underneath

How They Work Together

Every Pandas DataFrame column is secretly a NumPy array (or a Pandas extension type). When you call .values or .to_numpy() on a DataFrame, you get a NumPy array back. This interoperability is seamless.

Python — NumPy ↔ Pandas workflow 
import numpy as np
import pandas as pd

# ── Pandas → NumPy ─────────────────────────────────
df = pd.read_csv('sales.csv')
arr = df['revenue'].to_numpy()         # Pandas Series → NumPy array
matrix = df[['q1','q2','q3']].to_numpy()  # DataFrame → 2D NumPy array

# ── NumPy → Pandas ─────────────────────────────────
marks_arr = np.array([[85,92,78],[70,88,91]])
df = pd.DataFrame(
    marks_arr,
    columns=['Math','Physics','CS'],
    index=['Ali', 'Sara']
)

# ── Use NumPy inside Pandas operations ─────────────
df['log_revenue'] = np.log(df['revenue'])      # log transform
df['capped'] = np.clip(df['revenue'], 0, 1000)  # cap at 1000
df['zscore'] = (df['revenue'] - np.mean(df['revenue'])) / \
               np.std(df['revenue'])             # z-score normalize

# ── Typical DS Pipeline ────────────────────────────
# 1. Load with Pandas (handles CSV, types, labels)
df = pd.read_csv('data.csv')
# 2. Clean with Pandas (drop nulls, fix types)
df = df.dropna()
# 3. Extract numeric array for computation
X = df[feature_cols].to_numpy()
# 4. Process with NumPy (normalize, transform)
X_norm = (X - X.mean(axis=0)) / X.std(axis=0)
# 5. Feed into scikit-learn model (expects NumPy)
model.fit(X_norm, y)

  2. Calculate class-wide statistics (mean, std, percentiles) per subject.
  3. Normalize all marks using z-score normalization.
  4. Identify the top 10% of students (by average) and the bottom 10%.
  5. Convert to a Pandas DataFrame with student names as index and subject names as columns.
  6. Export to CSV with df.to_csv('results.csv').
