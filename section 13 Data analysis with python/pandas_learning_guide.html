01 · introduction
What is Pandas?
NumPy gives you fast arrays. Pandas gives those arrays labels, context, and the tools to work with real-world messy data.

The Missing Piece Between Raw Data and Analysis

Pandas (Panel Data / Python Data Analysis Library) is the most-used data manipulation library in Python. It introduces two key structures — Series and DataFrame — that let you work with labelled, heterogeneous data the way a spreadsheet does, but with the full power of Python and NumPy underneath.

If NumPy is the engine, Pandas is the dashboard. You'll use Pandas to load CSV files, clean messy columns, filter rows, compute group statistics, merge datasets, and prepare data for machine learning — all with concise, expressive code.

  • Labelled axes — rows and columns have names, not just positions
  • Mixed data types — one column can be integers, another strings, another dates
  • Missing data handling — NaN values are first-class citizens with dedicated tools
  • IO tools — read from CSV, Excel, SQL, JSON, Parquet, and more in one line
  • GroupBy engine — split → apply → combine, the foundation of aggregation
🔗
Pandas and NumPy
Every Pandas DataFrame column is backed by a NumPy array. All your NumPy knowledge — dtypes, vectorized operations, boolean indexing — transfers directly into Pandas. Pandas is NumPy with labels and ergonomics added on top.
02 · core structures
Series & DataFrame
Two objects. Everything in Pandas is built from them.

Series — A Labelled 1D Array

A Series is a single column of data with an index (labels for each row). Think of it as a dictionary that also supports NumPy operations.

Python — Series basics
import pandas as pd
import numpy  as np

# ── Create a Series ──────────────────────────────
marks = pd.Series([85, 92, 78, 96, 70],
                  index=['Ali', 'Sara', 'Hamza', 'Ayesha', 'Usman'])

print(marks)
# Ali      85
# Sara     92
# Hamza    78
# Ayesha   96
# Usman    70
# dtype: int64

# Access by label (loc) or position (iloc)
marks['Sara']        # 92
marks.iloc[2]        # 78 (Hamza, position 2)

# NumPy-style operations work on Series
marks[marks >= 80]   # Sara 92, Ayesha 96 (boolean indexing)
marks.mean()         # 84.2
marks * 1.1          # apply 10% bonus, labels preserved

# Useful Series properties
marks.values   # underlying NumPy array
marks.index    # Index(['Ali','Sara','Hamza','Ayesha','Usman'])
marks.dtype    # int64
marks.name     # None (you can set: marks.name = 'Score')

DataFrame — A Labelled 2D Table

A DataFrame is a collection of Series sharing the same index. It's your spreadsheet in Python — rows are observations, columns are variables.

DataFrame anatomy — index + columns + values
index ↓ NameMathPhysicsCSGrade

3Ayesha959298A
df.shape → (4, 5)  |  df.columns → ['Name','Math','Physics','CS','Grade']  |  df.index → RangeIndex(0,4)
Python — creating DataFrames
# ── From a dictionary ────────────────────────────
df = pd.DataFrame({

05 · selection
Selecting Data
The most important skill: getting exactly the rows and columns you need.
.loc vs .iloc — the two selectors
.loc → select by label (row name / column name) e.g. df.loc['Ali', 'Math']
.iloc → select by position (integer 0,1,2...) e.g. df.iloc[0, 2]

Rule: If you know the NAME → use .loc  |  If you know the NUMBER → use .iloc
Python — loc, iloc, column selection
df = pd.DataFrame({
    'Name':    ['Ali','Sara','Hamza','Ayesha','Usman'],
    'Math':    [85, 72, 55, 95, 40],
    'Physics': [76, 85, 60, 92, 38],
    'CS':      [95, 90, 70, 98, 45],
})

# ── Column selection ─────────────────────────────
df['Math']               # single column → Series
df[['Math', 'CS']]      # multiple columns → DataFrame

# ── .loc — label-based ───────────────────────────
df.loc[2]                 # row with index label 2 (Hamza's row)
df.loc[0:2]              # rows 0,1,2 — NOTE: loc is INCLUSIVE at end!
df.loc[0:2, 'Math':'CS']  # rows 0-2, cols Math through CS
df.loc[0, 'Physics']      # single cell: 76

# ── .iloc — position-based ───────────────────────
df.iloc[0]                # first row
df.iloc[0:3]             # rows 0,1,2 — iloc is EXCLUSIVE at end (like Python slices)
df.iloc[:3, 1:3]          # first 3 rows, columns 1 and 2
df.iloc[-1]              # last row
df.iloc[:, :-1]          # all rows, all cols except last

# ── at / iat — fast single-cell access ───────────
df.at[2, 'Math']          # 55 — fastest for single label access
df.iat[2, 1]              # 55 — fastest for single position access

# ── Setting values ───────────────────────────────
df.loc[4, 'Math'] = 50    # correct a specific value
df.loc[4, ['Math','Physics','CS']] = [50, 42, 48]  # set multiple
🚫
Never Use Chained Indexing
df['Math'][0] = 99 may silently fail or raise a SettingWithCopyWarning. Always use df.loc[0, 'Math'] = 99 for setting values. Chained indexing creates unpredictable behaviour.

06 · data cleaning
Cleaning Messy Data
80% of real data science work is cleaning. Pandas is built for this.

Handling Missing Values (NaN)

Real data is almost always incomplete. NaN (Not a Number) is Pandas' representation of missing data. Handling it correctly is critical — wrong decisions here propagate errors through your entire analysis.

Python — handling missing values
# ── Detect ────────────────────────────────────────
df.isnull()               # True/False mask for every cell
df.isnull().sum()         # total nulls per column
df.notnull()              # opposite
df[df['revenue'].isnull()]  # rows where revenue is missing

# ── Drop ──────────────────────────────────────────
df.dropna()              # drop any row with at least 1 NaN
df.dropna(axis=1)        # drop any COLUMN with at least 1 NaN
df.dropna(subset=['revenue'])  # drop rows where 'revenue' is NaN
df.dropna(thresh=4)      # keep rows with at least 4 non-null values

# ── Fill ──────────────────────────────────────────
df.fillna(0)                          # fill ALL NaN with 0
df['revenue'].fillna(df['revenue'].mean()) # fill with column mean
df['category'].fillna('Unknown')     # fill categorical with a label
df.fillna(method='ffill')            # forward-fill (use previous value)
df.fillna(method='bfill')            # backward-fill
df.interpolate()                       # linear interpolation

# ── Fill different columns differently ────────────
df.fillna({'revenue': df['revenue'].median(),
           'region':  'Unknown',
           'units':   0})

Fixing Data Types & Duplicates

After loading, columns often have wrong types. Dates come as strings, numbers as objects, booleans as 0/1. Fixing types is essential before any analysis.

Python — type conversion & duplicates
# ── Type conversion ───────────────────────────────
df['revenue'] = df['revenue'].astype(float)
df['units']   = df['units'].astype(int)
df['date']    = pd.to_datetime(df['date'])  # string → datetime

# Convert to category (saves memory for low-cardinality strings)
df['region'] = df['region'].astype('category')

# When astype fails (mixed "12" and "N/A" strings):
df['price'] = pd.to_numeric(df['price'], errors='coerce')
# errors='coerce' turns invalid values to NaN instead of crashing

# ── String cleaning ───────────────────────────────
df['name'] = df['name'].str.strip()          # remove whitespace
df['name'] = df['name'].str.lower()          # lowercase
df['name'] = df['name'].str.replace('_', ' ') # replace chars
df['name'].str.contains('Ali', na=False)     # boolean mask
df['code'].str.extract(r'(\d+)')             # regex extraction

# ── Duplicates ────────────────────────────────────
df.duplicated()                # True/False per row
df.duplicated().sum()          # count of duplicates
df.drop_duplicates()           # remove all duplicate rows
df.drop_duplicates(subset=['name', 'date'])  # based on specific cols
df.drop_duplicates(keep='last')              # keep last occurrence

# ── Rename & drop columns ─────────────────────────
df.rename(columns={'rev': 'revenue', 'qty': 'units'}, inplace=True)
df.drop(columns=['useless_col', 'temp'], inplace=True)

07 · filtering & sorting
Filtering & Sorting
Query your data like a database — get exactly the rows you need, in the right order.
Python — filtering and sorting
# ── Boolean filtering ─────────────────────────────
df[df['Math'] > 80]                         # high math scores
df[(df['Math'] > 80) & (df['CS'] > 85)]   # AND: both conditions
df[(df['Math'] < 60) | (df['CS'] < 60)]   # OR: either condition
df[~(df['Grade'] == 'F')]                  # NOT: negate

# ── .query() — cleaner syntax ─────────────────────
df.query('Math > 80 and CS > 85')
df.query('Grade in ["A", "B"]')
df.query('Math > @threshold')   # @ references a Python variable

# ── .isin() — match a list of values ──────────────
df[df['region'].isin(['North', 'South'])]
df[~df['region'].isin(['Unknown'])]    # exclude 'Unknown'

# ── .between() — range filter ─────────────────────
df[df['revenue'].between(1000, 5000)]   # inclusive

# ── Sorting ───────────────────────────────────────
df.sort_values('Math')                          # ascending
df.sort_values('Math', ascending=False)        # descending
df.sort_values(['Grade', 'Math'],              # multi-key sort
               ascending=[True, False])
df.sort_values('Math').head(5)                # bottom 5
df.nlargest(5, 'revenue')                     # top 5 by revenue (faster)
df.nsmallest(3, 'Math')                       # 3 lowest math scores

# ── Reset index after filtering ───────────────────
result = df[df['Math'] > 80].reset_index(drop=True)
# Without drop=True the old index becomes a column
08 · aggregation
GroupBy — Split · Apply · Combine
The most powerful pattern in data analysis. Group your data, compute something, get results back.
GroupBy mental model
SPLIT → divide DataFrame into groups by a key column (e.g. by 'region')
APPLY → run a function on each group (e.g. sum, mean, custom function)
COMBINE → collect results back into a single DataFrame
Python — groupby patterns
# Sales data: region, product, quarter, revenue, units
df = pd.DataFrame({
    'region':  ['North','South','North','South','North','South'],
    'product': ['A','A','B','B','A','C'],
    'revenue': [1200,1500,800,950,1100,2000],
    'units':   [60, 75, 40, 48, 55, 80],
})

# ── Basic aggregations ────────────────────────────
df.groupby('region')['revenue'].sum()
# region
# North    3100
# South    4450

df.groupby('region')['revenue'].mean()
df.groupby('region')['revenue'].agg(['sum', 'mean', 'max'])

# ── Multiple columns ──────────────────────────────
df.groupby('region')[['revenue', 'units']].sum()

# ── Group by multiple keys ────────────────────────
df.groupby(['region', 'product'])['revenue'].sum()

# ── Named aggregations (.agg with dict) ───────────
result = df.groupby('region').agg(
    total_revenue = ('revenue', 'sum'),
    avg_units     = ('units',   'mean'),
    num_orders    = ('revenue', 'count'),
    max_sale      = ('revenue', 'max'),
).reset_index()
print(result)

# ── Transform — adds result back as column ─────────
# Each row gets its GROUP's total (not a summary!)
df['region_total'] = df.groupby('region')['revenue'].transform('sum')
df['pct_of_region'] = df['revenue'] / df['region_total'] * 100

# ── Filter entire groups ──────────────────────────
# Keep only groups where total revenue > 3500
big_regions = df.groupby('region').filter(
    lambda g: g['revenue'].sum() > 3500
)
🏆
transform() vs agg() — Key Difference
agg() collapses each group to one row (summary table). transform() returns a value for every original row (same index as input) — perfect for adding group statistics as new columns without losing your rows.

09 · combining data
Merging & Joining
Real analysis always involves multiple tables. Pandas makes SQL-style joins simple.
Join types visualized
inner
Only rows matching in BOTH tables
left
All rows from LEFT + matched from right (NaN if no match)
right
All rows from RIGHT + matched from left
outer
ALL rows from both tables (NaN where no match)
Python — merge, join, concat
students = pd.DataFrame({
    'id':   [1, 2, 3, 4],
    'name': ['Ali', 'Sara', 'Hamza', 'Ayesha'],
})

marks = pd.DataFrame({
    'student_id': [1, 2, 3, 5],   # id=5 has no student!
    'math':       [85, 72, 55, 90],
    'cs':         [95, 90, 70, 88],
})

# ── pd.merge() — like SQL JOIN ────────────────────
inner = pd.merge(students, marks,
                 left_on='id', right_on='student_id',
                 how='inner')   # 3 rows (id 1,2,3 match)

left  = pd.merge(students, marks,
                 left_on='id', right_on='student_id',
                 how='left')    # 4 rows; Ayesha has NaN marks

# ── When column names match: use 'on' ─────────────
pd.merge(df1, df2, on='student_id', how='inner')

# ── Merge on index ────────────────────────────────
pd.merge(df1, df2, left_index=True, right_index=True)

# ── pd.concat() — stack DataFrames ───────────────
# Vertical stack (more rows)
all_data = pd.concat([df_jan, df_feb, df_mar], ignore_index=True)

# Horizontal stack (more columns)
combined = pd.concat([df_info, df_scores], axis=1)

# ── Useful: merge diagnostic ──────────────────────
pd.merge(df1, df2, on='id', how='outer', indicator=True)
# _merge column shows 'left_only','right_only','both'
# Great for finding unmatched rows!

10 · custom logic
Apply & Transform
When built-in functions aren't enough, apply your own logic to any row or column.
Python — apply, map, applymap
# ── Series.map() — element-wise on a Series ───────
df['grade_num'] = df['Grade'].map({'A': 4, 'B': 3, 'C': 2, 'F': 0})

# ── Series.apply() — apply a function ─────────────
df['category'] = df['Math'].apply(lambda x: 'High' if x >= 80 else 'Low')

# ── DataFrame.apply() — apply across rows or cols ─
# axis=0 → apply function to each COLUMN
df[['Math','CS']].apply(lambda col: col - col.mean())  # centre each col

# axis=1 → apply function to each ROW
df['total'] = df[['Math','Physics','CS']].apply(sum, axis=1)

# ── Custom function on rows ───────────────────────
def assign_scholarship(row):
    if row['Math'] >= 90 and row['CS'] >= 90:
        return 'Full'
    elif row['Math'] >= 80 or row['CS'] >= 80:
        return 'Partial'
    else:
        return 'None'

df['scholarship'] = df.apply(assign_scholarship, axis=1)

# ── np.where — fast conditional column ────────────
df['result'] = np.where(df['Math'] >= 60, 'Pass', 'Fail')

# ── pd.cut / pd.qcut — binning ────────────────────
df['grade_band'] = pd.cut(
    df['Math'],
    bins=[0, 59, 69, 79, 89, 100],
    labels=['F', 'D', 'C', 'B', 'A']
)
df['quartile'] = pd.qcut(df['revenue'], q=4,
                          labels=['Q1','Q2','Q3','Q4'])
⚡
apply() is slow — use vectorized alternatives first
apply() loops row-by-row in Python — it's 10–100× slower than vectorized operations. Always prefer: np.where() for conditionals, .str methods for strings, +/-/*/ for math. Use apply() only when no vectorized option exists.
11 · time series
Working with Dates
Time-based data is everywhere. Pandas has world-class datetime support built in.
Python — datetime operations
# ── Parse dates ───────────────────────────────────
df['date'] = pd.to_datetime(df['date'])                 # string → datetime
df['date'] = pd.to_datetime(df['date'], format='%d/%m/%Y') # custom format

# ── Extract components ─────────────────────────────
df['year']    = df['date'].dt.year
df['month']   = df['date'].dt.month
df['day']     = df['date'].dt.day
df['weekday'] = df['date'].dt.day_name()   # 'Monday', 'Tuesday' ...
df['quarter'] = df['date'].dt.quarter       # 1, 2, 3, 4

# ── Filter by date ────────────────────────────────
df[df['date'].dt.year == 2024]
df[df['date'] >= '2024-06-01']      # string comparison works!
df[df['date'].dt.month == 12]     # all December rows

# ── Set date as index for time-series power ────────
df = df.set_index('date').sort_index()
df['2024']                        # all rows from 2024
df['2024-01':'2024-06']           # Jan to Jun 2024

# ── Resampling — groupby for time ─────────────────
df.resample('M')['revenue'].sum()   # monthly totals
df.resample('Q')['revenue'].mean()  # quarterly averages
df.resample('W')['revenue'].sum()   # weekly totals

# ── Rolling windows ────────────────────────────────
df['7day_avg'] = df['revenue'].rolling(window=7).mean()  # 7-day moving avg
df['30d_sum']  = df['revenue'].rolling(window=30).sum()  # 30-day rolling sum

# ── Shift — lag/lead for comparisons ──────────────
df['prev_month']  = df['revenue'].shift(1)            # previous period
df['mom_growth']  = ((df['revenue'] - df['prev_month'])
                    / df['prev_month']) * 100            # month-over-month %
12 · pitfalls
Common Mistakes
The bugs that catch everyone. Know them before they catch you.
❌ Wrong
df[df['Math'] > 80]['CS'] = 99 # SettingWithCopyWarning # May not actually update df!
Chained indexing creates a copy — assignment silently fails.
✅ Correct
df.loc[df['Math'] > 80, 'CS'] = 99 # Single indexer → always safe
Always use .loc[row_mask, column] for conditional assignment.
❌ Wrong
df.dropna(inplace=True) df.sort_values('Math', inplace=True) # inplace=True mutates silently # hard to debug, chain-hostile
inplace=True makes code harder to reason about and debug.
✅ Correct
df = df.dropna() df = df.sort_values('Math') # Or chain: df = (df.dropna() .sort_values('Math') .reset_index(drop=True))
Reassign to df — supports method chaining and debugging.
❌ Wrong
for i in range(len(df)): df.loc[i, 'total'] = ( df.loc[i,'Math'] + df.loc[i,'CS']) # Loops over rows — extremely slow
Iterating over DataFrame rows is 100–1000× slower than vectorization.
✅ Correct
df['total'] = df['Math'] + df['CS'] # Vectorized — instant, clean
Use column arithmetic, apply(), or np.where() — never loop rows.
❌ Wrong
df.loc[df['date'] > '2024-01-01'] # If 'date' column is dtype object # this does string comparison! # '2024-12' < '2024-2' as strings
Date comparisons only work correctly on proper datetime columns.
✅ Correct
df['date'] = pd.to_datetime(df['date']) df.loc[df['date'] > '2024-01-01'] # Now it's real datetime comparison
Always convert date columns with pd.to_datetime() first.
🔍
Debug Tip: Check dtype First
90% of Pandas bugs come from wrong column types. When something doesn't work as expected, run df.dtypes and df.info() immediately. Is a number stored as object? Is a date a string? Fix the dtype and the bug usually disappears.

You have a dataset of 500 orders: order date, product, category, region, quantity, unit price, and customer ID. Build a complete analysis pipeline from raw data to insights.

Python — complete e-commerce analysis
import pandas as pd
import numpy  as np

# ════════════════════════════════════════════
# STEP 1: Generate synthetic dataset
# ════════════════════════════════════════════
np.random.seed(42)
n = 500
categories = ['Electronics', 'Clothing', 'Food', 'Books']
regions    = ['North', 'South', 'East', 'West']

df = pd.DataFrame({
    'date':       pd.date_range('2024-01-01', periods=n, freq='D')
                     [np.random.randint(0, n, n)],
    'category':   np.random.choice(categories, n),
    'region':     np.random.choice(regions, n),
    'quantity':   np.random.randint(1, 10, n),
    'unit_price': np.random.uniform(5, 500, n).round(2),
    'customer_id':np.random.randint(1000, 1200, n),
})

# Introduce some missing values (real-world!)
mask = np.random.random(n) < 0.05
df.loc[mask, 'unit_price'] = np.nan

# ════════════════════════════════════════════
# STEP 2: Clean
# ════════════════════════════════════════════
print("=== Missing values ===")
print(df.isnull().sum())

df['unit_price'] = df.groupby('category')['unit_price'].\
                       transform(lambda x: x.fillna(x.median()))
# Fill missing price with the CATEGORY median — smarter than overall median!

# ════════════════════════════════════════════
# STEP 3: Feature Engineering
# ════════════════════════════════════════════
df['revenue'] = df['quantity'] * df['unit_price']
df['month']   = df['date'].dt.month
df['quarter'] = df['date'].dt.quarter
df['weekday'] = df['date'].dt.day_name()

df['price_tier'] = pd.cut(
    df['unit_price'],
    bins=[0, 50, 150, 350, float('inf')],
    labels=['Budget', 'Mid', 'Premium', 'Luxury']
)

# ════════════════════════════════════════════
# STEP 4: Analysis
# ════════════════════════════════════════════

# Revenue by category
cat_rev = (df.groupby('category')
             .agg(total_revenue=('revenue','sum'),
                  num_orders   =('revenue','count'),
                  avg_order    =('revenue','mean'))
             .round(2)
             .sort_values('total_revenue', ascending=False))
print("\n=== Revenue by Category ===\n", cat_rev)

# Monthly trend
monthly = (df.set_index('date')
             .resample('M')['revenue']
             .sum()
             .round(2))
print("\n=== Monthly Revenue ===\n", monthly)

# Top 10 customers by spend
top_customers = (df.groupby('customer_id')['revenue']
                    .sum()
                    .nlargest(10)
                    .reset_index())
print("\n=== Top 10 Customers ===\n", top_customers)

# Region × Category pivot table
pivot = df.pivot_table(
    values='revenue',
    index='region',
    columns='category',
    aggfunc='sum'
).round(0)
print("\n=== Revenue Pivot: Region × Category ===\n", pivot)

# Weekend vs Weekday performance
df['is_weekend'] = df['date'].dt.dayofweek >= 5
weekend_analysis = (df.groupby('is_weekend')['revenue']
                       .agg(['mean', 'sum', 'count'])
                       .round(2))
weekend_analysis.index = ['Weekday', 'Weekend']
print("\n=== Weekend vs Weekday ===\n", weekend_analysis)

# ════════════════════════════════════════════
# STEP 5: Export results
# ════════════════════════════════════════════
cat_rev.to_csv('category_performance.csv')
pivot.to_csv('region_category_pivot.csv')
print("\n✅ Analysis complete. Files exported.")

Method Chaining — Writing Clean Pandas

Professional Pandas code chains operations together into readable pipelines. Instead of creating many intermediate variables, use parentheses and chain methods:

Python — method chaining (pro style)
# ── Amateur style — many temp variables ───────────
df1 = df.dropna(subset=['revenue'])
df2 = df1[df1['revenue'] > 0]
df3 = df2.sort_values('revenue', ascending=False)
df4 = df3.reset_index(drop=True)

# ── Pro style — clean chain ────────────────────────
result = (
    df
    .dropna(subset=['revenue'])
    .query('revenue > 0')
    .assign(
        month    = lambda x: x['date'].dt.month,
        revenue  = lambda x: x['quantity'] * x['unit_price'],
    )
    .groupby(['region', 'month'])['revenue']
    .sum()
    .reset_index()
    .sort_values('revenue', ascending=False)
    .head(10)
)
